\# 🛡️ PhishGuard



\## Phishing URL Detection and Cybersecurity Awareness System



PhishGuard is a rule-based cybersecurity awareness system that analyzes website URLs for common phishing indicators and provides a simple risk assessment.



The project is designed to help users understand common characteristics of suspicious URLs and improve their awareness of phishing attacks.



\## 🎯 Objectives



\- Identify common phishing indicators in URLs

\- Calculate a simple risk score

\- Display detected warning signs

\- Provide cybersecurity safety recommendations

\- Educate users about phishing and safe browsing



\## 🔍 Detection Features



PhishGuard analyzes the following URL characteristics:



1\. HTTPS verification

2\. URL length

3\. @ symbol detection

4\. Subdomain analysis

5\. IP address detection

6\. Special character analysis

7\. Suspicious keyword detection

8\. Multiple hyphen detection

9\. URL shortener detection

10\. Suspicious URL word detection



\## 📊 Risk Classification



| Score | Risk Level |

|---|---|

| 0–2 | 🟢 Low Risk |

| 3–4 | 🟠 Suspicious |

| 5–10 | 🔴 High Risk |
